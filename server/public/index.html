Descarga la app

APK para Android 8 o superior. La medición con realidad aumentada necesita un teléfono compatible con ARCore (la mayoría de gama media y alta). En otros teléfonos puedes medir con una foto y una tarjeta de referencia.

⬇ Descargar APK Abrir versión web
  1. Descarga el archivo en tu teléfono Android.
  2. Ábrelo y permite «instalar apps de esta fuente» si te lo pide.
  3. Entra con tu cuenta, o prueba con la cuenta demo tienda@demo.app / demo1234.

El APK se está compilando. Mientras tanto, usa la versión web.
