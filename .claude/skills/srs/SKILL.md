1. Lee `docs/SRS.md`. Si necesitas detalle literal (entradas, proceso, errores) y existe `docs/2_SRS_DIMENSIONA_IEEE830.pdf`, lee la página del RF.
2. Para la tarea, enumera: requisito(s) afectados, entradas, proceso, mensajes de error exactos (en español), criterio de aceptación y prueba PR.
3. Señala requisitos transversales que aplican siempre: RNF-15 (confiabilidad visible), RF-15 (metros internos), ROT-01/03/05/06.
4. Si una decisión contradice el SRS, detente y avísalo en lugar de improvisar.
